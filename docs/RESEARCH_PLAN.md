# FURA-MAPPO 研究计划

当前版本是研究路线草案。WP-01A 和 WP-01B 已完成并形成四类外生需求稳定基线；当前进入 WP-01C 数据与配置工具只读设计阶段。环境、指标和正式实验预算将在对应工作包中逐步冻结。

## 1. 核心假设

### H1：真实未来信息具有控制价值

在资源受限且需求具有时空变化时，Oracle 未来需求配置应优于纯反应式配置。该假设是继续开展预测和 MARL 的前置门槛。

### H2：预测价值取决于需求非平稳性和资源条件

预测收益不会在所有场景中一致出现。预计需求漂移速度、状态切换频率、突发强度、资源供需比、移动成本和截止约束共同决定收益区间。

### H3：不确定性质量影响主动预置的风险

点预测可能在高误差或 OOD 条件下造成过度预置。经过校准的概率预测或不确定性特征应帮助策略在收益与风险之间权衡。

### H4：预测引导 MAPPO 能学习近似 Oracle 的分散式行为

在不直接获得真实未来的条件下，MAPPO 可利用预测及不确定性形成协同预置策略，并在合理 OOD 变化下优于反应式和不使用不确定性的策略。

## 2. 研究模块

### 2.1 外生需求生成

- 平稳 Poisson：可复现和统计正确性的基础对照；
- Drifting Hotspot：连续时空漂移；
- Markov Switching：离散需求状态切换；
- Burst Demand：稀疏、短时高强度事件。

需求模块只生成外生任务，不读取策略或服务结果。上述四类过程已完成实现和验收；WP-01C 将增加配置、可复现数据产物和分析工具，但不得改变科学语义。

### 2.2 资源服务环境

后续环境需要明确：

- 区域、位置和移动；
- 资源容量与任务服务；
- 服务时长和截止时间；
- 未服务、延迟、移动和闲置成本；
- 集中训练、分散执行的信息结构。

在环境冻结前，不定义最终奖励权重。

### 2.3 基线层

至少比较：

- 静态或均匀配置；
- 当前需求反应式配置；
- 基于历史均值或短期趋势的启发式；
- 使用真实未来需求的 Oracle；
- 后续预测点估计配置；
- 后续概率或不确定性感知配置。

### 2.4 预测层

预测器需要输出与控制接口兼容的信息，例如未来窗口内各区域需求分布、均值、分位数或不确定性摘要。预测精度和控制收益必须分别评价，不能只用预测误差替代策略效果。

### 2.5 决策层

在 Oracle 门槛成立后，再实现 MAPPO。后续消融至少区分：

- 无预测；
- 仅点预测；
- 点预测加不确定性；
- 真实未来 Oracle；
- 不同预测窗口和信息质量。

## 3. 实验结构

### 3.1 分布内评估

训练和测试来自同一需求过程族及冻结参数范围，但使用独立种子和轨迹。

### 3.2 分布外评估

OOD 维度候选包括：

- 更快漂移；
- 不同状态切换频率；
- 更强或更密集突发；
- 整体需求水平变化；
- 空间热点位置或尺度变化；
- 资源供需比变化。

具体 OOD 边界须在最终实验前冻结。

### 3.3 预测价值相图

计划按以下轴构建相图或响应面：

- 预测误差或校准误差；
- 需求变化速度或突发程度；
- 资源供需比；
- 移动或预置成本；
- 预测窗口；
- 策略相对反应式和 Oracle 的收益。

目标不是证明“预测总是有用”，而是识别预测有用、无效或有害的条件边界。

## 4. 科学控制

- 使用固定配置和配对种子比较方法；
- 训练、验证和测试种子分离；
- 调参预算对各方法公平；
- Oracle 不参与学习，只作为信息上界或机制验证；
- 报告平均效果、区间估计、失败案例和计算成本；
- 不根据最终测试结果反复调整 OOD 边界；
- 预测指标与控制指标同时报告。
