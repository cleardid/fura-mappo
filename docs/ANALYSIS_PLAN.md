# 统计分析计划

状态：研究设计草案，尚未冻结最终环境指标、样本量和多重比较方案。正式主实验开始前必须版本化冻结。

## 1. 分析目标

1. 验证真实未来信息相对反应式方法的控制价值；
2. 比较预测点估计、概率预测和不确定性感知策略；
3. 量化预测质量与控制收益之间的关系；
4. 评价 ID 和 OOD 条件下的平均性能、变异性和失败模式；
5. 构建预测价值相图并识别收益边界。

## 2. 比较层级

### 门槛比较

- 反应式基线 vs Oracle；
- 若 Oracle 没有稳定优势，暂停 MAPPO 主线并重新检查问题设定。

### 方法比较

后续至少包含：

- 静态或均匀配置；
- 反应式启发式；
- 历史均值或趋势启发式；
- Oracle；
- 点预测决策；
- 不确定性感知决策；
- 无预测 MAPPO；
- 点预测 MAPPO；
- 不确定性感知 MAPPO。

## 3. 指标框架

最终指标在环境工作包冻结。候选指标包括：

- 未服务需求或服务率；
- 响应/等待时间；
- deadline miss rate；
- 任务完成量；
- 资源利用率和空闲率；
- 移动或重配置成本；
- 综合成本或归一化回报；
- 相对反应式收益；
- 相对 Oracle 的最优差距；
- 训练和推理计算成本。

必须同时报告组成指标，不能只报告可能掩盖权衡的单一加权奖励。

## 4. 实验单位和随机性

- 正式比较使用预先生成或可精确重放的外生需求轨迹；
- 方法间优先使用相同需求种子进行配对；
- 训练种子与评估需求种子分别记录；
- 训练、验证、ID 测试和 OOD 测试种子集合互不重叠；
- 不因结果不理想删除随机种子；
- 异常运行排除规则必须在主实验前定义。

## 5. 区间估计和效应

计划报告：

- 每种方法和场景的均值、中位数及分布；
- 配对差值及置信区间；
- 绝对差值和相对差值；
- 相对 Oracle gap；
- 必要时使用按种子配对的 bootstrap 或其他预先冻结方法。

置信水平、bootstrap 次数和多重比较校正将在样本量规划后冻结。不得在观察最终结果后选择最有利的统计方法。

## 6. ID/OOD 设计

ID 和 OOD 参数边界在正式测试前冻结。候选 OOD 维度：需求水平、热点漂移速度、Markov 切换频率、突发强度/持续时间、空间分布和资源供需比。

结果应分场景报告，不把差异很大的 OOD 条件简单汇总成一个均值。

## 7. 预测评价

预测层至少区分：

- 点预测误差；
- 概率预测质量或校准；
- 不确定性排序能力；
- 预测窗口；
- 预测计算成本；
- 下游控制收益。

高预测精度不自动等于高控制价值，必须分析两者关系。

## 8. 预测价值相图

相图至少考虑以下轴的子集：

- 需求非平稳程度；
- 预测误差或校准误差；
- 资源供需比；
- 移动成本；
- 预测窗口；
- 策略相对基线收益。

应展示无收益和负收益区域，而不仅展示最佳区域。

## 9. 调参和计算预算

- 各学习方法使用可比调参预算；
- 测试集不参与模型或超参数选择；
- 失败运行和重新运行原因进入实验台账；
- 大型实验必须记录运行时、硬件和资源消耗；
- 最终随机种子数量通过先验方差估计或小规模试验确定，而不是按结果显著性追加。

## 10. WP-01A 已完成的统计测试

WP-01A 只验证需求过程统计正确性，不进行方法优劣推断。冻结参数：

```text
seed = 314159
num_steps = 20_000
intensities = [0.2, 0.8, 2.0]
```

逐区域检查：

```text
abs(empirical_mean - lambda) <= 8 * sqrt(lambda / num_steps)
```

零强度区域使用精确零断言。该测试固定 seed、按区域执行，不使用相对误差处理零强度，也不允许任意放宽容差掩盖实现错误。
