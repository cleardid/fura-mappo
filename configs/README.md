# 配置目录

本目录用于后续可复现实验配置。当前 `WP-01A` 明确不实现 YAML 配置、配置加载器或命令行配置覆盖，因此本目录暂不新增需求过程配置文件。

## 计划结构

在相关工作包冻结后，配置预计按职责组织：

```text
configs/
├── demand/
├── env/
├── forecast/
├── algo/
└── experiment/
```

目录和字段只有在对应工作包确认后才能创建，不得为未来功能提前设计复杂层级。

## 最终实验记录要求

每次正式实验必须能够关联：

- 解析后的完整配置；
- 随机种子；
- Git Commit；
- 运行环境摘要；
- 数据版本或生成配置；
- 评价协议和结果文件位置。

大型生成数据、日志和模型不得提交 GitHub。WP-01C 将决定需求配置格式、序列化接口和命令行入口。
